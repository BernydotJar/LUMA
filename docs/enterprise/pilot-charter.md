# Enterprise Pilot Charter (Proposal, not yet accepted)

| Topic | Draft definition |
| --- | --- |
| Scope | One high-ticket live/hybrid program, Hotmart retained, verified learner activation, AI tutor, Learning Twin, coach intelligence |
| Cohort | 50–100 eligible learners; **pilot sample**, not maximum technical users |
| Timeline | 60 calendar days after security/merchant readiness approval |
| Baseline | Pre-pilot activation, practice, attendance, coach follow-up and costs agreed with owner |
| Product | Existing live sessions retained; recordings optional by consent, baseline/diagnostics separate from verified mastery |
| Measures | Activation %, first-value latency, WAU/eligible, practice completion, rubric-assessed independent capability, human interventions, satisfaction |
| Coach leverage | Learners/coach, follow-up minutes per learner, intervention success/time and workload |
| Responsibilities | Client merchant account/product IDs, coach permissions, data rights; LUMA webhook/entitlement, reporting, reliability; named support/incident owner |
| Technical gate | Signed sandbox purchase/refund/replay, tenancy/role audit, failure-recovery tests, secrets/access, privacy/voice agreement |
| Costs | Pilot fee plus measured usage bounds and written excess/exit terms; no invented transaction fee |
| Exit | Data export/deletion policy, revoke access, performance report, go/no-go based on pre-agreed criteria |

## Go / no-go

**GO** only when merchant event audit, verified learner access and revocation, zero unauthorized tenant crossover, valid learner-evidence behavior, baseline and support owner are independently evidenced. **NO-GO** for unsigned webhook acceptance, real personal data in public demo, unverifiable loss of payments, missing reversal behavior or unsupported contractual SLA. This pilot measures engagement/progress/coach leverage, not causation of revenue uplift.
