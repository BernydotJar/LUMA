# Source-Guided Premium System

## Why source-guided

The Practitioner Module 3 material already contains strong metaphors and conceptual structures. LUMA should amplify those structures rather than cover them with generic ed-tech graphics.

### Source-derived anchors

From the supplied Module 3 PDF:

- Communication is framed as a sequence from thought to emotion to action and objective.
- P.A.S. are described as automatic, rapid, rigid thought patterns with recognizable linguistic signals.
- Change is organized across behavior, internal process, and internal state.
- Logical levels structure environment, behavior, capability, beliefs/values, identity, and mission.
- Beliefs are described as filters through which experience is interpreted.
- Mental maps distinguish representation from territory.
- Identity appears as a deeper layer of self-description and meaning.

These structures are directly useful for visual semantics.

## Experience expressions

- warm glass;

### Editorial Warmth

- champagne / cream;
- deep brown;
- strong typography;
- photographic/editorial spacing;
- minimal motion.

### Architectural Focus

- graphite / tobacco / aubergine;
- planes;
- structural grids;
- decisive contrast.

### Technical Precision

- dark neutral;
- thin rules;
- measured motion;
- exact charts;
- crisp hierarchy.

These are optional presentation modes. They must never be automatically selected from gender.

## Motion rules

- semantic, not decorative;
- 4–8 second ambient loops;
- no bounce;
- no confetti;
- no springy toy motion;
- use opacity, rotation, refraction, depth, and slow orbital movement;
- respect prefers-reduced-motion.

## 3D generation policy

Generated 3D WebP or video assets may replace CSS placeholders only when:

1. the metaphor is already approved in the semantic atlas;
2. the asset loops seamlessly;
3. transparency is preserved;
4. it remains decorative;
5. there is no textual information embedded in the image;
6. it passes performance budget and reduced-motion fallback;
7. the asset looks like premium conceptual art, not a children's-learning icon.

## Source note

The concept atlas is grounded in the supplied Module 3 PDF and the controlled source inventory. The visual metaphors are product-design interpretations, not claims that the source itself prescribes a specific visual design.
