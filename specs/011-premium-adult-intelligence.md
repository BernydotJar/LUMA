# SPEC 011 — Premium Adult Intelligence

## Product principle

LUMA should feel like premium adult learning intelligence.

The experience is designed around autonomy, relevance, real-world application, identity, reflection, and demonstrated progress. It must avoid visual or interaction patterns that make adult learning feel juvenile, gamified for children, or cosmetically gendered.

The Learning Twin remains a competitive advantage of LUMA while staying cognitively lightweight for the coachee.

## Source-guided visual semantics

The visual language is derived from the actual Practitioner Module 3 content rather than from generic AI illustration.

The Module 3 corpus supplies the following semantic structures:

- pensamiento → emoción → acción → objetivo;
- Pensamientos Automáticos Saboteadores (P.A.S.);
- comportamiento / proceso interior / estado interior;
- niveles lógicos;
- creencias;
- valores;
- mapas mentales;
- identidad;
- cambio personal.

These concepts become visual metaphors, not literal school illustrations.

### Semantic object map

| Learning concept | Premium visual metaphor | Product use |
| --- | --- | --- |
| P.A.S. | refractive prism / filter | Practice |
| Progress | orbital field / constellation | Progress |
| Niveles lógicos | architectural strata | Coach Insight |
| Human intervention | bridge / threshold | Human Intervention |
| Creencias | lens / layered glass | Belief work |
| Valores | axis / balanced constellation | Values |
| Identidad | mirror / double surface | Identity |
| Mapas mentales | cartographic field | Journey / perspective |
| Cambio | fold / threshold / metamorphosis | Transformation |

The semantic object must never be the only carrier of meaning. It is decorative and explanatory support; accessible text remains authoritative.

## Premium adult design language

The experience combines:

- editorial premium;
- sophisticated wellness;
- luxury knowledge product;
- intelligent software;
- optimistic 1970s futurism;
- Swiss information hierarchy;
- restrained liquid glass;
- warm analog materiality.

It avoids:

- kawaii;
- mascot-first learning;
- smiling brains;
- cartoon trophies;
- childish rockets;
- emoji-as-concept;
- game-map progression;
- gendered stereotypes.

## Gender-aware without gender stereotypes

LUMA must not infer visual treatment from sex or gender.

Instead, experience expression can later be adapted from explicit preference or interaction evidence using modes such as:

- Organic Reflection;
- Editorial Warmth;
- Architectural Focus;
- Technical Precision.

These are experience modes, not personality diagnoses and not protected-attribute proxies.

## Product messaging boundary

Client-facing product copy must describe outcomes and transformation.

Preferred:
- "De contenido experto a inteligencia de aprendizaje."
- "Tu conocimiento se convierte en experiencias que enseñan."
- "Cada concepto conserva su fuente, contexto y criterio de calidad."
- "Revisión experta · Procedencia preservada · Cambios trazables."

Avoid as headline or product value:
- "La IA propone. El experto publica."
- "AI-native authoring."
- prompt / pipeline / retrieval / graph implementation language.

Operational architecture belongs in:
- trust;
- governance;
- architecture;
- coach/admin diagnostics.

## Coachee experience

The coachee should feel:

- "Esto me entiende."
- "Esto se adapta."
- "Estoy avanzando."

The coachee sees:
- next useful action;
- qualitative progress;
- journey;
- practice;
- contextual support.

## Coach experience

The coach should feel:

- "Puedo ver qué está ocurriendo."
- "Entiendo por qué."
- "Sé dónde intervenir."

The coach may see:
- Learning Twin;
- evidence;
- bounded inference;
- confidence;
- provenance;
- intervention context.

## Buyer experience

The buyer should understand:

"LUMA convierte conocimiento experto en aprendizaje individualizado y medible."

The underlying moat may include:
- Learning Twin;
- Knowledge Graph;
- grounded retrieval;
- reflection;
- evidence ledger;
- human governance.

Those mechanisms do not need to be the headline.

## Acceptance criteria

1. Content Intelligence contains no "La IA propone. El experto publica." headline.
2. Content Intelligence contains no client-facing "AI-native authoring" label.
3. Semantic object system exists with variants for Practice, Progress, Coach Insight, and Human Intervention.
4. Semantic objects are abstract, premium, and aria-hidden.
5. Practice uses the P.A.S. prism/filter metaphor.
6. Progress uses orbital-field semantics.
7. Coach Insight uses architectural-strata semantics.
8. Human Intervention uses bridge/threshold semantics.
9. Semantic mapping is traceable to source concepts from Module 3.
10. Experience modes are documented without gender inference.
11. Existing coachee / coach role separation remains intact.
12. WCAG A/AA, E2E, production build, layout, and production dependency audit pass.
