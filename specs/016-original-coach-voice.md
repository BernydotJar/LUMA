# SPEC 016 — Original Seres Coach Voice

## Product intent

Create an original voice for Seres de Excelencia learning experiences that feels real, adult and culturally coherent.

The requested reference is Mary Cardona Lenis. LUMA must not reproduce or imitate an identifiable person’s voice without explicit authorization, rights documentation and provider-policy review.

## Original voice direction

Working name: **Seres Coach Voice**.

High-level traits:

- mature Colombian / Latin American Spanish;
- warm and close;
- direct, never patronizing;
- composed authority;
- reflective pauses;
- clear diction;
- natural emotional range;
- conversational rather than announcer-like;
- capable of firm questions without sounding punitive.

These are broad performance characteristics, not a request to copy an individual’s voiceprint, signature cadence or recognizable delivery.

## Pedagogical use

Voice enters only when listening or speaking improves the learning task:

- communication simulation;
- spoken reflection;
- Socratic exchange;
- retrieval practice;
- coach-session preparation.

Voice is not added simply to read interface text.

## Rights gate

### Original voice

Required:

- commissioned performer or provider-licensed synthetic voice;
- commercial-use terms;
- data retention and deletion review;
- clear attribution/consent contract where applicable.

### Direct voice clone

Additional requirements:

- explicit written consent from the voice owner;
- intended-use scope;
- revocation procedure;
- provider verification;
- legal review;
- visible disclosure where required.

Without those requirements, direct cloning is denied.

## Aside research

Aside is useful as inspiration for local-first capture, transcription, privacy and note UX. It is not the selected speech-synthesis or voice-cloning provider.

## Provider abstraction

```text
Learning Move
  -> modality policy
  -> voice provider adapter
  -> audio/transcript
  -> consent + retention policy
  -> learning event
```

The voice provider has no authority to update the Learning Twin directly.

## First prototype

A communication practice:

1. present a short workplace scenario;
2. learner records an initial spoken response;
3. transcript is shown and editable;
4. learner separates event / thought / emotion;
5. learner records a revised response;
6. LUMA records the speaking artifact and observable learning event.

Text-only completion remains available.
