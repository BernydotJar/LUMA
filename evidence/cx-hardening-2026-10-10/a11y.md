# LUMA WCAG 2.2 AA / interaction QA

**Result:** 18 automated axe route/theme scans passed (zero total violations, zero serious/critical); **not** a full WCAG 2.2 AA certificate.

**Scope:** 390x844 guest Chrome Playwright. Routes /learn, /login, /onboarding, /learn/experiences, /learn/session/pas and /studio; themes SE, Light, Dark. WCAG tags 2 A, 2 AA, 2.1 A/AA, 2.2 AA. See independent-results.json raw violations lists; all status HTTP 200.

**Keyboard smoke:** 25 Tab focus events collected in each theme at 390x844, with visibly focused targets. Exactly three per theme overlapped the bottom tab-bar rectangle because they were the links **Hoy**, **Ruta** and **Programa** contained inside the bottom nav itself; this is normal, not proof of hidden focus. The recommendation explanation expanded with the Enter key in all three themes. See keyboard-results.json. Full no-mouse learner/coach path and all dialog focus return were not exercised.

**Touch target size:** 390 mobile /learn, three sub-44px controls: goal link h38, recommendation explanation h40, secondary start practice h40. Fix this as a UX comfort target, not as an axe failure. The primary hero CTA passed >=44px and hit-testing in all mobile tested sizes.

**Motion:** viewport script created contexts with reducedMotion=reduce; did not assert every CSS transition or screenshot under all preferences. Native iOS safe area, TalkBack/VoiceOver, live-classroom/certificate signed-in routes, 200% real browser zoom/text enlargement, color vision modes and manual contrast checks remain OPEN/BLOCKED.

**Exploratory only:** Applying document.body CSS zoom=200% under mobile Chromium caused html scrollWidth=561 at clientWidth=390 (+171 px). This is NOT authentic browser zoom and must not be reported as verified WCAG 1.4.10 failure. Use actual browser zoom/text scaling for an authoritative verdict.

**CX heuristic observations:** Hick: journey detail progressively disclosed and clear primary CTA; Fitts: mobile CTA safe but smaller secondary controls; Jakob: standard navigation/summary; cognitive load: minimize repetition and ambiguous scores; common region: related practice grouped; goal-gradient: meaningful verified progress, never locally injected completion passed off as remote evidence; aesthetic-usability: avoid excessive transparency/animation without task performance benefit.

**Acceptance not satisfied:** at least one actual VoiceOver/TalkBack pass, keyboard focus on all privileged routes, genuine 200% zoom, dialogs/error states and screen-reader announcements. Automated axe does not replace them.
