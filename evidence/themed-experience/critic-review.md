# Three-Theme Superuser Experience — Critic Review

## Review question

Can LUMA express institutional SE, Liquid Light and Nocturne themes without fragmenting the product or altering learning semantics?

## Pass — theme boundary

Theme changes color, light, material and iconography. It does not change:

- recommendation logic;
- evidence;
- role permissions;
- source truth;
- learning events.

## Pass — Seres de Excelencia

The theme uses measured official blue, pink/coral and plum with the official public logo. Pink is treated as institutional transformation color rather than a gender signal.

## Pass — Liquid Light

The theme uses light system materials, restrained transparency, one active color, reduced-motion support and reduced-transparency fallback. It does not copy Apple product screens, SF Symbols or proprietary interface components.

## Pass — Nocturne

The dark theme extends the existing premium coach language across coachee, coach and superuser surfaces.

## Pass — superuser model

`/experience` presents coachee and coach together and exposes theme selection. It clearly labels future role/profile architecture rather than claiming persistent multi-user identity is complete.

## Pass — iconography

Eighteen deterministic SVG assets exist: six meanings × three themes. The 3dicon animation path remains approval-gated.

## Controlled boundaries

- theme preference is browser-local in the showcase;
- generated 3D stills require an authenticated image-provider bridge;
- direct voice cloning is blocked without explicit rights;
- private videos remain inventoried and are not publicly exposed.

## Verdict

PASS within the documented showcase boundary.
